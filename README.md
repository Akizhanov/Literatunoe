# Спящий рыцарь — задания по легенде

Сайт с автоматической проверкой ответов (максимум 10 баллов) и ссылками на рабочий лист в Google Диске.

## Как опубликовать

Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку / (root), затем Save. GitHub покажет адрес после завершения публикации.

## Как запустить локально

Откройте index.html в браузере. Сборка и установка зависимостей не нужны.

## Оценивание

Семь вопросов по 1 баллу и три соответствия по 1 баллу. Два верных качества дают 1 балл; одно — 0. Для вопроса о местоположении принимаются Кокшетау, Боровое или Бурабай. Открытые ответы проверяются по словарю: нестандартную формулировку может проверить учитель.

Ответы обрабатываются в браузере и не отправляются на сервер. Скачивание и печать открывают файл Google Диска, указанный учителем.
