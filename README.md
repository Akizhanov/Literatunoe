# Спящий рыцарь — задания по легенде

Интерактивный сайт по литературе: семь вопросов и три соответствия, автоматическая проверка из 10 баллов, разбор ответов и ссылки на рабочий лист в Google Диске.

Сайт работает без сборки и сервера. Откройте `index.html` или включите GitHub Pages.

## Публикация на GitHub Pages

1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Выберите ветку main и папку / (root), затем нажмите Save.
4. После завершения публикации GitHub покажет адрес сайта.

## Проверка ответов

За каждый из семи вопросов — 1 балл. За каждое из трёх соответствий — 1 балл. Для вопроса 6 нужны два качества, для вопроса 7 принимаются Кокшетау, Боровое и Бурабай. Открытые ответы проверяются по словарю; необычную формулировку может уточнить учитель.

Ответы учеников обрабатываются в браузере и не отправляются на сервер. Ссылки на скачивание и печать открывают указанный учителем файл в Google Диске.
